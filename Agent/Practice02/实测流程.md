# Practice02 实测流程(验证指南)

目标:验证 `getDate`、`isLeapYear` 和 10 个文件工具**真的被模型调用**,而不是模型自己在编答案。

> 本文是验证步骤 + 预期结果,不是预先写好的实测记录。
> 每一组问完之后,把真实输出填到文末的「实测记录」表格里。

---

## 一、怎么判断工具真的被调用了

程序里每个工具调用都会打印两行:

```
  [调用工具 getDate({"format": "%Y"})]
  [工具结果] 当前日期时间:2026
```

- 第一行:模型请求调用工具,参数是模型自己填的;
- 第二行:工具真实执行后的返回值;
- 之后模型说的话才是基于工具结果的回答。

**如果只有模型的话、没有这两行**,说明模型没调工具、纯靠嘴答的,这次验证无效,换个更明确的问法重问。

---

## 二、准备工作

1. 启动 LM Studio,加载模型并打开本地服务器(默认 `http://127.0.0.1:1234/v1`)。
2. 配置:把 [config.example.ini](config.example.ini) 复制为 `config.ini`,
   确认 `base_url`、`model`、`api_key` 三个值和 LM Studio 一致。
3. 启动程序(完整版):

   ```
   cd Agent\Practice02
   python chat.py
   ```

   看到 `你:` 就是好了。

> 程序启动时已自动把终端切到 UTF-8,一般不会再乱码;如果仍有乱码,
> 换 Windows Terminal 运行,或在前面加 `set PYTHONIOENCODING=utf-8`。

## 三、验证清单

### 第 1 组:getDate 基本功能

```
现在几点了?
```

预期(时间以实际为准):

```
  [调用工具 getDate({})]
  [工具结果] 当前日期时间:2026-10-30 20:15:32
```

**验收**:`[工具结果]` 的时间和任务栏时钟对一下,差几秒算正常(中间有推理耗时)。

### 第 2 组:getDate 换格式

```
今天几号?星期几?
```

预期模型会传 `format` 参数(如 `"%Y-%m-%d %A"`),工具按 strftime 重排后返回。
**验收**:日期、星期和实际一致。这一组顺带验证 `format` 参数透传。

### 第 3 组:isLeapYear 普通年份

```
2024年是闰年吗?
```

预期:

```
  [调用工具 isLeapYear({"year": 2024})]
  [工具结果] 2024 年是闰年
```

### 第 4 组:isLeapYear 世纪年陷阱 ★重点

```
闰年是不是4年一次?帮我算算 1900、2000、2100。
```

预期(三个 year 参数按 4/100/400 规则计算):

```
1900 → 不是闰年(能被 4 和 100 整除,但不能被 400 整除)
2000 → 是闰年(能被 400 整除)
2100 → 不是闰年
```

如果 1900 被答成闰年,说明计算逻辑错了。我们的实现就是三行取模判断,
`tests` 里也有边界用例,理论上不会错。

### 第 5 组:跨工具链式调用

```
先用工具查一下现在是哪一年,再判断那一年是不是闰年。
```

预期:先 `[调用工具 getDate(...)]` 拿年份,再 `[调用工具 isLeapYear({"year": ...})]`,
两个工具串起来。**验收**:两个工具调用的顺序正确,年份是工具返回的,不是模型猜的。

### 第 6 组:文件工具

```
帮我在当前目录建一个 demo 目录,把"你好,世界"写进 demo/hello.txt,
读出来念给我听,再告诉我这个文件是什么类型。
```

预期会依次看到 `createDirectory` → `createFile` → `readFile` → `getFileType` 的调用与结果,
最后模型把文件内容复述出来。**验收**:`demo/hello.txt` 真的出现在程序运行的目录里
(文件工具以运行目录为基准)。

### 第 7 组:错误也要返回文本,不打断对话

```
读一个不存在的文件 ghost.txt。
```

预期:`[工具结果] 错误:文件不存在:...`,然后模型能看懂错误并解释给你听,
对话不会崩。**验收**:程序继续等你输入下一句。

## 四、排错

| 现象 | 原因与解决 |
| --- | --- |
| 报「连不上模型服务」 | LM Studio 没启动或没开本地服务器;检查 `config.ini` 的 `base_url` 端口(默认 1234) |
| 启动时报 `KeyError` 或 `NoSectionError: llm` | 目录里没有 `config.ini`,或没写 `[llm]` 段标题;复制 config.example.ini 再改 |
| 模型答了但完全没有 `[调用工具]` 行 | ① 模型觉得不用调工具,换更明确的问法;② 模型不支持 function call,换支持工具调用的模型 |
| 中文乱码 | 在 Windows Terminal 运行,或先 `set PYTHONIOENCODING=utf-8` |
| 文件工具报「错误:...」 | 正常现象——参数不对、路径不存在等都会转成文本返回,让模型自己修正重试 |
