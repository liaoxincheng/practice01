用 Python 写一个 chat.py，要求：

1. 程序启动后读取同目录下的 config.ini，里面是三行配置：base_url、model、api_key。
2. 用户在屏幕上输入一句提示词。
3. 程序先输出三个减号 --- 作为分割。
4. 按 OpenAI 兼容格式把请求 POST 到 base_url 加 /chat/completions，带上 model 和用户输入的那句话；api_key 不为空时放进 Authorization 请求头。
5. 把模型返回的回答打印到屏幕上。
6. 程序结束。

只用 Python 标准库，不要安装第三方包。不要多轮对话循环，不要日志，不要多余的封装和注释，代码越短越好。
